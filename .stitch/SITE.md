# LINE&LOOP Site

## 1. Site Vision
LINE&LOOP is a premium e-commerce platform for handmade, slowly crafted ladies' garments. The site should exude a high-end fashion feel with modern minimalist layouts, prioritizing high-quality product imagery and typography while maintaining an artisanal narrative.

## 2. Global Elements
- **Header:** Top announcement bar, logo, minimal navigation links, Search & Bag icons.
- **Footer:** Brand description, detailed navigation links (Shop, About, Journal, Account, Track Order), Newsletter signup.
